# cometline.github.io

Static marketing site for Cometline, intended for GitHub Pages.

## Files

- `index.html` — landing page markup
- `styles.css` — site styling
- `static/` — hero video, app icons, UI screenshots, and cobalt editorial backgrounds (`visual-nebula.jpg`, `visual-constellation.jpg`, `visual-comet.jpg`)

## Publishing on GitHub Pages

Use GitHub Pages with deployment from the repository root on the default branch.
